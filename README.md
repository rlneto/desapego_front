# Vitrine Digital

## Descrição

Frontend de um acervo de produtos à venda, conectando ao backend do projeto.

![img](https://github.com/rlneto/desapego_front/blob/main/public/assets/vitrine.png?raw=true)


## Sobre o deploy

Não foi feito por uma razão bem simples. O projeto é uma aplicação full-stack, com controladores e persistência de dados. Para fazer a implantação do projeto em sua total funcionalidade, seria necessária uma escolha entre restrringir a funcionalidade da inclusão e edição de produtos ou de fazer todo um tratamento dos dados sob a lgpd, além da necessidade de implementar toda uma rastreabilidade a fim de evitar fraudes, o que vai muito além do escopo do projeto.
